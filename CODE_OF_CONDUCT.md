# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept feedback gracefully, and keep discussion about the work. Harassment, personal attacks and discrimination are not tolerated.

Report problems privately by contacting the maintainer through their GitHub profile. Maintainers may remove comments, issues or contributors that break these rules.
