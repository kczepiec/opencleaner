# Agent rules for OpenCleaner

Instructions for AI coding agents working in this repo (Claude Code, Codex, OpenBot and others).

## Project

Native macOS 14+ app. `App/` is SwiftUI, `Sources/CleanKit` is UI-free logic, `Sources/opencleaner-mcp` is the MCP server. The Xcode project is generated by XcodeGen from `project.yml` and is not committed.

## Commands

- Test: `swift test`
- Build: `xcodegen generate && xcodebuild -project OpenCleaner.xcodeproj -scheme OpenCleaner -configuration Release -derivedDataPath build CODE_SIGN_IDENTITY=- build`
- Release zip: `tools/release.sh <version>`

## Rules

- Never run a destructive action (`mo clean`, `mo optimize`, cache cleaning, uninstall, `simctl delete`) to test. Use dry-run and sample data.
- Anything that deletes must preview, confirm and prefer the Trash. Keep the MCP write tools off by default and behind `confirm: true`.
- New logic goes in `CleanKit` with a test. Keep views thin.
- Make the smallest change that solves the task. Do not refactor or reformat unrelated code, and add no dependencies without asking.
- Match the dark theme in `Theme.swift` and `Palette.swift`. Respect Reduce Motion and accessibility labels.
- App text is Polish. No em dash or en dash in text.
- Do not commit `build/`, `dist/`, `.build/` or the generated `*.xcodeproj`.
- No secrets, tokens or personal paths in code or docs.
- Commit messages: imperative, no co-author or tool attribution lines.
- Do not push, open pull requests or publish releases unless the maintainer asks.
